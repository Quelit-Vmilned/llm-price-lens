# Fuzzy Model Search

## 1. 架构

- 使用 Fuse.js 在浏览器本地搜索，不调用 AI API，不访问远程搜索服务。
- 数据规模较小时不得引入 Web Worker、搜索服务或向量索引。
- 搜索结果必须确定性：相同查询与相同数据产生相同顺序。

## 2. 搜索字段与权重

- 搜索字段：模型名、模型 ID、厂商、系列、别名、标签、摘要。
- 权重从高到低：精确模型名 > 模型 ID > 别名 > 厂商 > 标签 > 摘要。
- 支持中文、英文、别名、拼写近似和描述关键词。

## 3. 语义标签

- “便宜”“强大”“适合编程”等描述只能匹配人工维护的 `tags`、`aliases` 或 `summary` 字段。
- 程序不得凭空推断模型能力、价格档位或用途。
- 人工维护字段必须能在数据源中追溯到条目。

## 4. 测试要求

- 拼写错误（如 `sonet` -> `sonnet`）。
- 中英文别名。
- 中文描述关键词（如 `写代码`、`推理模型`、`长上下文`、`开源`）。
- 厂商和系列查询。
- 无结果情况。
- 空查询情况。
- 结果排序稳定性。

## 5. 表现

- 搜索在本地同步完成，不阻塞首屏关键渲染，不引入大型运行时。
- 不匹配任何记录时，页面显示明确的“无匹配”状态，而不是空白或错误。
